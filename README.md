# PopClip Extensions

## 安装方式

- 目录型扩展：双击对应 `*.popclipext` 目录安装。
- 压缩包扩展：双击 `*.popclipextz` 安装。

## 当前扩展

### 搜索类

- `Google搜索.popclipext`
- `YouTube搜索.popclipext`
- `百度搜索.popclipext`
- `知乎搜索.popclipext`
- `哔哩哔哩搜索.popclipext`
- `抖音搜索.popclipext`
- `小红书搜索.popclipext`

### 工具类

- `字数统计.popclipext`
- `颜色预览.popclipext`
- `在终端运行.popclipext`
- `在Ghostty运行.popclipext`
- `Obsidian.popclipextz`
- `发送到ChatGPT.popclipext`
- `发送到Telegram.popclipext`

### 地址与公司

以下扩展按选中文字自动判断，不符合条件时不显示：

- `百度地图.popclipext`：选中地址时用百度地图搜索
- `高德地图.popclipext`：选中地址时用高德地图搜索
- `天眼查.popclipext`：选中公司名时用天眼查搜索
- `BOSS直聘.popclipext`：选中公司名时用 BOSS 直聘搜索
- `脉脉.popclipext`：选中公司名时用脉脉搜索

### Hermes

- `发送到Hermes.popclipext`：选中任意文字，发送到固定的「PopClip 快捷发送」Hermes 会话。首次点击时创建一个会话，之后复用同一会话，避免产生大量一次性会话。
